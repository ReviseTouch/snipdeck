# Snipdeck

**Быстрая, управляемая с клавиатуры _панель_ для создания снимков экрана в Windows.**

Захватывайте область, держите снимки поверх всех окон, размечайте их,
индексируйте по OCR и ищите среди сотен скриншотов в одной плотной галерее —
и всё это в нативном приложении на Rust с программно отрисованным интерфейсом [Slint](https://slint.dev).

## ✨ Ключевые возможности

- 🖱️ **Захват по модификатору + перетаскивание.** Удерживайте `Win` и выделите область перетаскиванием; модификаторы определяют, что
  произойдёт с результатом — плавающее окно, буфер обмена, только галерея (матрица ниже).
- 🧊 **Захват с предварительной заморозкой** (`Win`+`Shift`+`Space`). Затемняет и замораживает экран *до* того, как вы
  начнёте выделять, поэтому всплывающие подсказки и другие чувствительные к кликам элементы интерфейса остаются на снимке.
- 📌 **Плавающие снимки.** Захваченные снимки остаются закреплёнными поверх всех окон в виде лёгких оверлеев без рамок, которые можно
  перетаскивать, изменять в размере, закреплять, обрезать, поворачивать/отражать и убирать.
- ✏️ **Встроенный редактор аннотаций.** Перо, маркер, фигуры, стрелки и текст с полным цветовым
  кругом HSV, регулируемым размером и непрозрачностью, масштабированием и отменой/повтором (подробнее).
- 🔍 **Встроенный OCR.** Каждый снимок индексируется по OCR в фоновом режиме с помощью системного движка
  (`Windows.Media.Ocr`) — без загрузки моделей, без сети, полностью локально.
- 🌐 **OCR + перевод.** Читайте текст снимка на другом языке прямо на месте (более 30 целевых языков, с
  избранными, которые можно отметить звёздочкой).
- 🗂️ **Мощная галерея.** Полнотекстовый поиск по тексту OCR, метаданным окна, монитору и пути;
  фильтрация по статусу / содержимому / размеру / дате; виртуализированная сетка, которая остаётся плавной при тысячах снимков.
- 📤 **Поделиться и загрузить.** Панель «Поделиться» Windows, новое письмо (Simple MAPI), системный редактор изображений
  или хостинг изображений — загрузки **включаются по желанию через явное диалоговое окно согласия**.
- 🌍 **23 языка**, автоматически определяемые из вашей ОС и переключаемые с панели инструментов.
- 🌗 **Светлая / тёмная темы**, домашний значок в системном трее и запуск при входе **без записи в реестр**.

## ⌨️ Сочетания клавиш для захвата

Удерживайте `Win`, затем выделите область **левой** кнопкой мыши. Добавляйте модификаторы, чтобы изменить, что
произойдёт со снимком:

| Сочетание клавиш | Результат |
| --- | --- |
| `Win` + перетаскивание | Плавающий снимок на экране |
| `Win`+`Ctrl` + перетаскивание | Плавающий снимок **и** копирование в буфер обмена |
| `Win`+`Alt` + перетаскивание | Только буфер обмена (не добавляется в галерею) |
| `Win`+`Shift` + перетаскивание | Только галерея (без плавающего окна) |
| `Win`+`Ctrl`+`Shift` + перетаскивание | Галерея **и** буфер обмена, без плавающего окна |
| `Win`+`Shift`+`Space`, затем перетаскивание | **Сначала заморозка** — заморозьте экран, затем выделяйте на неподвижном изображении |

Также можно щёлкнуть правой кнопкой по значку в трее → **Новый снимок**, чтобы взвести одноразовый захват перетаскиванием без
удержания `Win`.

## ✏️ Редактор аннотаций

Щёлкните правой кнопкой по любому снимку → **Аннотировать**, чтобы открыть сфокусированный редактор в стиле Telegram, который располагается поверх
ваших снимков.

- **Инструменты** — перо от руки, маркер, прямоугольник, эллипс, линия, стрелка и текст.
- **Полный цветовой круг HSV** с ползунком яркости — выбирайте *любой* цвет, а не фиксированную палитру.
- **Ползунки размера и непрозрачности** с мигающим предпросмотром размера на изображении, запоминаемые для каждого инструмента.
- **Увеличение / уменьшение / по размеру** для точной работы; холст панорамируется при увеличении.
- **Отмена / повтор / очистка**, а также `Esc`, `Ctrl`+`Z`, `Ctrl`+`Y`.
- При **Сохранении** штрихи сводятся на изображение в полном разрешении (чёткие, в нативном размере).

Живой предпросмотр и сохранённый результат создаются одним и тем же кодом, поэтому **что вы видите, то и получаете**.

## 🖱️ Действия по правому клику

Щёлкните правой кнопкой по плавающему снимку **или** миниатюре в галерее:

- **Копировать** изображение в буфер обмена
- **OCR + буфер обмена** — выполнить OCR и скопировать распознанный текст
- **OCR + перевод** — открыть всплывающее окно перевода
- **Аннотировать** — открыть редактор выше
- **Поделиться** — панель «Поделиться» Windows, **Почта** (вложение MAPI), открыть в **редакторе** (Paint)
  или **Загрузить** на хостинг изображений
- **Преобразовать** — поворот (90° / 180°), отражение по горизонтали / вертикали
- **Обрезать** (потяните маркеры внутрь) и **Изменить размер**
- **Скрыть с экрана** / **Удалить**

## 📦 Установка

### Скачать

Возьмите последний `snipdeck.exe` со страницы [**Releases**](https://github.com/hasantr/snipdeck/releases).
Это единый автономный переносимый исполняемый файл — без установщика.

### Сборка из исходного кода

Требования: [Rust](https://rustup.rs/) (stable) и Windows 10 или 11.

```powershell
git clone https://github.com/hasantr/snipdeck.git
cd snipdeck
cargo build --release
```

Бинарный файл появится в `target\release\snipdeck.exe`.

## 🌍 Языки

Snipdeck полностью локализован. При первом запуске он выбирает ваш язык по локали ОС;
переопределить его можно в любой момент из **меню глобуса** на панели инструментов.

> Английский · Испанский · Упрощённый китайский · Хинди · Арабский · Португальский · Русский · Японский ·
> Немецкий · Французский · Корейский · Итальянский · Турецкий · Индонезийский · Вьетнамский · Польский · Украинский ·
> Нидерландский · Персидский · Тайский · Бенгальский · Урду · Румынский

Всё приложение — как интерфейс Slint (`@tr`), так и сообщения на стороне Rust (`i18n::t`) — читается из
**одного gettext-файла `.po` на язык** в `lang/<code>/LC_MESSAGES/snipdeck.po`, встроенного в
бинарный файл во время сборки (без зависимости от gettext во время выполнения).

<details>
<summary><b>Добавление или обновление перевода</b></summary>

1. Новые строки оборачиваются в `@tr("…")` (в `.slint`) или `i18n::t("…")` (в Rust).
2. `lang/snipdeck.pot` — это шаблон, в котором перечислены все английские строки.
3. Скопируйте новый msgid в каждый `lang/<code>/LC_MESSAGES/snipdeck.po` и заполните его `msgstr` —
   сохраняя плейсхолдеры (`{}`, `{e}`, `{url}`, `{path}`) и escape-последовательности `\r\n` без изменений.
4. Чтобы добавить новый язык, создайте его `.po` и добавьте код в `LANGUAGES` и `po_source()`
   в `src/i18n.rs`.

</details>

## 🔒 Конфиденциальность и безопасность

- **Захват и OCR полностью локальны.** OCR использует встроенный движок `Windows.Media.Ocr`; ничего
  не отправляется куда-либо для захвата или индексации.
- **Запуск при входе работает без записи в реестр.** Snipdeck помещает обычный ярлык в вашу папку `shell:Startup`
  вместо записи значения `HKCU\…\Run` — это обычный, видимый пользователю механизм, который
  позволяет избежать ключа реестра автозапуска, чаще всего помечаемого антивирусами / средствами EDR.
- **Загрузки включаются по желанию.** Ничто не покидает вашу машину без явного диалога согласия, который
  указывает место назначения. Не загружайте конфиденциальное содержимое на хостинг, доступный всем по ссылке.
- **OCR + перевод использует сеть.** На публичную конечную точку Google `translate_a` для перевода отправляется
  только распознанный по OCR *текст*; больше он нигде не используется.

## ⚙️ Конфигурация

Настройки хранятся в формате JSON и создаются при первом запуске. Окна настроек пока нет — отредактируйте
файл напрямую, затем перезапустите Snipdeck.

| Путь | Содержимое |
| --- | --- |
| `%APPDATA%\Snipdeck\settings.json` | Пользовательские настройки (ниже) |
| `%LOCALAPPDATA%\Snipdeck\` | `snips.db`, `state.json` и `cache\` с изображениями и миниатюрами |
| `Pictures\Snipdeck\` | Папка по умолчанию для *Сохранить* |

<details>
<summary><b>Избранные ключи <code>settings.json</code></b></summary>

| Ключ | По умолчанию | Значение |
| --- | --- | --- |
| `language` | `"auto"` | Код языка интерфейса или `"auto"` для следования ОС |
| `dark_theme` | `true` | Светлая или тёмная оболочка |
| `upload_service` | `"catbox"` | Хостинг изображений для *Загрузить*: `"catbox"` (без ключа) или `"imgur"` |
| `imgur_client_id` | `""` | Imgur Client-ID, требуется только когда `upload_service` равно `"imgur"` |
| `translate_target` | `"en"` | Код целевого языка по умолчанию для OCR-перевода |
| `translate_favs` | `["en","es","fr","de","it","pt","ru","ar"]` | Языки быстрого выбора во всплывающем окне перевода |
| `default_format` | `"png"` | Расширение по умолчанию для *Сохранить* |

**Сервисы загрузки** — *catbox.moe* (по умолчанию) не требует учётной записи или ключа, но анонимные загрузки
**впоследствии нельзя удалить**. *Imgur* требует бесплатный Client-ID (зарегистрируйтесь один раз на
imgur.com → Settings → Applications). В обоих случаях изображение не публикуется в списках, но любой, у кого есть
ссылка, может его открыть, и оно не зашифровано.

</details>

## 🧩 Архитектура

Однопоточный цикл событий Slint управляет интерфейсом; системные хуки и блокирующая работа выполняются в собственных
потоках и передают результаты обратно по каналам, опустошаемым раз за тик.

<details>
<summary><b>Карта модулей</b></summary>

| Модуль | Назначение |
| --- | --- |
| `src/app/` | Состояние приложения, цикл на каждый тик, действия интерфейса, модель галереи |
| `src/capture.rs`, `src/dxgi_capture.rs` | Захват монитора (DXGI Desktop Duplication, резервный вариант GDI) |
| `src/mouse_trigger.rs`, `src/native_mouse_trigger.rs` | Низкоуровневые хуки мыши/клавиатуры, которые запускают и ведут захват снимков |
| `src/slint_overlay.rs`, `ui/overlay.slint` | Полноэкранный оверлей выделения (живой или замороженный) |
| `src/floating.rs`, `ui/floating.slint` | Плавающие окна снимков (перетаскивание, изменение размера, обрезка, рамка) |
| `src/annotate.rs`, `ui/annotate.slint` | Редактор аннотаций (сведение tiny-skia, круг HSV, масштабирование) |
| `src/ocr.rs` | Обёртка `Windows.Media.Ocr` (в рабочем потоке) |
| `src/translate.rs`, `src/translate_popup.rs` | Всплывающее окно OCR-перевода |
| `src/share.rs`, `src/upload.rs` | Панель «Поделиться» / почта MAPI / редактор / загрузка на хостинг изображений |
| `src/tray.rs`, `src/autostart.rs`, `src/single_instance.rs` | Значок в трее, запуск при входе, защита от запуска нескольких экземпляров |
| `src/snip.rs`, `src/settings.rs`, `src/paths.rs` | Сохранение галереи (SQLite + FTS), настройки, пути |
| `src/i18n.rs`, `lang/` | i18n во время выполнения + встроенные gettext-каталоги `.po` (23 языка) |

</details>
