# Snipdeck

**Быстрая, управляемая с клавиатуры _панель_ для создания снимков экрана в Windows.**

<sub>Бесплатное приложение с открытым исходным кодом от <a href="https://revisetouch.com"><b>ReviseTouch</b></a>.</sub>

Захватывайте область, держите снимки поверх всех окон, размечайте их,
индексируйте по OCR и ищите среди сотен скриншотов в одной плотной галерее —
и всё это в нативном приложении на Rust с программно отрисованным интерфейсом [Slint](https://slint.dev).

## ✨ Ключевые возможности

- 🖱️ **Захват по модификатору + перетаскивание.** Удерживайте `Win` и выделите область перетаскиванием; модификаторы определяют, что
  произойдёт с результатом — плавающее окно, буфер обмена, только галерея ([матрица ниже](#️-сочетания-клавиш-для-захвата)).
- 🧊 **Захват с предварительной заморозкой** (`Win`+`Shift`+`Space`). Затемняет и замораживает экран *до* того, как вы
  начнёте выделять, поэтому всплывающие подсказки и другие чувствительные к кликам элементы интерфейса остаются на снимке.
- 📌 **Плавающие снимки.** Захваченные снимки остаются закреплёнными поверх всех окон в виде лёгких оверлеев без рамок, которые можно
  перетаскивать, изменять в размере, закреплять, обрезать, поворачивать/отражать и убирать.
- ✏️ **Встроенный редактор аннотаций.** Перо, маркер, фигуры, стрелки и текст с полным цветовым
  кругом HSV, регулируемым размером и непрозрачностью, масштабированием и отменой/повтором ([подробнее](#️-редактор-аннотаций)).
- 🧩 **Коллаж.** Соберите несколько снимков в одно изображение — сеткой, выровненными рядами или «кладкой» (masonry),
  с отступами, скруглёнными углами и фоном, — и оно сохранится в галерее как новый снимок.
- 🔍 **Встроенный OCR.** Каждый снимок индексируется по OCR в фоновом режиме с помощью системного движка
  (`Windows.Media.Ocr`) — без загрузки моделей, без сети, полностью локально.
- 🌐 **OCR + перевод.** Читайте текст снимка на другом языке прямо на месте (29 целевых языков, с
  избранными, которые можно отметить звёздочкой).
- 🗂️ **Мощная галерея.** Полнотекстовый поиск по тексту OCR, метаданным окна, монитору и пути;
  фильтрация по статусу / содержимому / размеру / дате; виртуализированная сетка, которая остаётся плавной при тысячах снимков
  ([обзор](#️-галерея)).
- 📤 **Поделиться и загрузить.** Панель «Поделиться» Windows, новое письмо (Simple MAPI), системный редактор изображений
  или хостинг изображений — catbox.moe, Imgur или **ваш собственный сервер** из файла ShareX `.sxcu`
  ([подробнее](#-свой-хостинг-изображений)). Каждая загрузка **сначала спрашивает**.
- 🌍 **23 языка**, автоматически определяемые из вашей ОС и переключаемые в меню `⋯` на панели инструментов.
- 🌗 **Светлая / тёмная темы**, домашний значок в системном трее и запуск при входе **без записи в реестр**.

## ⌨️ Сочетания клавиш для захвата

Удерживайте `Win`, затем выделите область **левой** кнопкой мыши. Добавляйте модификаторы, чтобы изменить, что
произойдёт со снимком:

| Сочетание клавиш | Результат |
| --- | --- |
| `Win` + перетаскивание | Плавающий снимок на экране |
| `Win`+`Ctrl` + перетаскивание | Плавающий снимок **и** копирование в буфер обмена |
| `Win`+`Alt` + перетаскивание | Только буфер обмена (не добавляется в галерею) |
| `Win`+`Shift` + перетаскивание | Только галерея (без плавающего окна) |
| `Win`+`Ctrl`+`Shift` + перетаскивание | Галерея **и** буфер обмена, без плавающего окна |
| `Win`+`Shift`+`Space`, затем перетаскивание | **Сначала заморозка** — заморозьте экран, затем выделяйте на неподвижном изображении |

Также можно щёлкнуть правой кнопкой по значку в трее → **Новый снимок**, чтобы взвести одноразовый захват перетаскиванием без
удержания `Win`.

### Глобальные горячие клавиши

Помимо `Win` + перетаскивание, Snipdeck регистрирует пять настраиваемых глобальных горячих клавиш:

| Горячая клавиша | Действие |
| --- | --- |
| `Win`+`Alt`+`H` | Показать / скрыть все снимки на экране |
| `Ctrl`+`Alt`+`Shift`+`A` | Новый снимок |
| `Ctrl`+`Alt`+`Shift`+`C` | Новый снимок **и** копирование в буфер обмена |
| `Ctrl`+`Alt`+`Shift`+`X` | Только буфер обмена |
| `Ctrl`+`Alt`+`Shift`+`G` | Открыть галерею |

Измените их с помощью ключей `hotkey_*` в `settings.json`. В Wayland глобальными
сочетаниями клавиш управляет рабочее окружение: при первом запуске они лишь
предлагаются, а потом их меняют в настройках клавиатуры вашего рабочего окружения.

## ✏️ Редактор аннотаций

Щёлкните правой кнопкой по любому снимку → **Аннотировать**, чтобы открыть сфокусированный редактор в стиле Telegram, который располагается поверх
ваших снимков.

- **Инструменты** — перо от руки, маркер, прямоугольник, эллипс, линия, стрелка и текст.
- **Полный цветовой круг HSV** с ползунком яркости — выбирайте *любой* цвет, а не фиксированную палитру.
- **Ползунки размера и непрозрачности** с мигающим предпросмотром размера на изображении, запоминаемые для каждого инструмента.
- **Увеличение / уменьшение / по размеру** для точной работы; холст панорамируется при увеличении.
- **Отмена / повтор / очистка**, а также `Esc`, `Ctrl`+`Z`, `Ctrl`+`Y`.
- По нажатию **Сохранить** штрихи сводятся на изображение в полном разрешении (чёткие, в нативном размере).

Живой предпросмотр и сохранённый результат создаются одним и тем же кодом, поэтому **что вы видите, то и получаете**.

## 🖱️ Действия по правому клику

Щёлкните правой кнопкой по плавающему снимку **или** миниатюре в галерее:

- **Копировать** изображение в буфер обмена
- **OCR + Буфер** — выполнить OCR и скопировать распознанный текст
- **OCR + Перевод** — открыть всплывающее окно перевода
- **Аннотировать** — открыть редактор выше
- **Поделиться** — панель «Поделиться» Windows, **Почта** (вложение MAPI), открыть в **редакторе** (Paint)
  или **Загрузить** на хостинг изображений ([на какой](#-свой-хостинг-изображений))
- **Преобразовать** — поворот (90° / 180°), отражение по горизонтали / вертикали
- **Обрезать** (потяните маркеры внутрь) и **Изменить размер**
- **Убрать с экрана** / **Удалить**

## 🗂️ Галерея

Одна строка панели инструментов; всё остальное — в один клик.

- **Новый** делает снимок. Под его стрелкой — **Снимок + Буфер** и **Только буфер**, у каждого своя горячая клавиша.
- Рядом — **Коллаж** и **Выбрать цвет**, а остаток строки занимает поле поиска:
  `Ctrl`+`F` — перейти в него, `Esc` — очистить.
- **Фильтр** собирает статус, содержимое, размер и дату в одной панели. Активные фильтры отображаются метками
  под панелью инструментов; каждый можно снять по отдельности или все сразу кнопкой **Сбросить фильтры**.
- В **`⋯`** — то, что меняется редко: плавающие снимки на панели задач, тёмная тема, запуск при
  входе, язык, очистка галереи и «О Snipdeck».
- Строка состояния показывает, сколько снимков отображается, и содержит меню **Сортировка** и размер карточек **S / M / L**.

Наведите курсор на карточку, чтобы увидеть быстрые действия; щёлкните по ней правой кнопкой, чтобы открыть [всё остальное](#️-действия-по-правому-клику).

## 📤 Свой хостинг изображений

**`⋯` → Загрузить на** выбирает, куда **Загрузить** отправляет снимок: catbox.moe (по умолчанию, без учётной записи),
Imgur или ваш собственный хостинг. Чтобы добавить его, выберите **Добавить из файла .sxcu…** и укажите файл
пользовательского загрузчика ShareX — этот формат уже предлагают Zipline, XBackBone, Chevereto и большинство
самостоятельно размещаемых серверов изображений, так что вручную писать ничего не нужно.

Snipdeck отправляет изображение как данные формы multipart или как двоичное тело запроса, с заголовками, аргументами
и параметрами запроса из файла, и извлекает ссылку с помощью `{json:…}`, `{regex:…}`, `{header:…}` или `{response}` —
в том числе в форме `$json:…$` из ShareX 12. Файл, которому нужно больше (запрос ввода, случайное значение, ответ
в XML, назначение, не являющееся хостингом изображений), отклоняется уже при импорте с указанием причины, а не
приводит к ошибке при первой загрузке.

Прежде чем что-либо отправить, собственное окно Snipdeck называет хостинг и его адрес и объясняет, что означает
загрузка; по завершении оно показывает ссылку, которая уже скопирована.

## 📦 Установка

### Скачать

**Windows** — возьмите `snipdeck-windows-x64.exe` со страницы
[**Releases**](https://github.com/ReviseTouch/snipdeck/releases). Единый
переносимый исполняемый файл, без установщика.

**Linux (x64)** — возьмите `snipdeck-linux-x64.tar.gz` с той же страницы:

```bash
tar xzf snipdeck-linux-x64.tar.gz
cd snipdeck-linux-x64
./install.sh          # into ~/.local, no root; --uninstall reverses it
```

Затем запустите его из меню приложений. Это не вопрос вкуса: в Wayland портал
рабочего стола определяет идентификатор приложения по записи `.desktop`, через которую
оно было запущено, а без неё отказывается привязывать какие-либо глобальные
сочетания клавиш.

### Сборка из исходного кода

Требования: [Rust](https://rustup.rs/) (stable).

```bash
git clone https://github.com/ReviseTouch/snipdeck.git
cd snipdeck
cargo build --release
```

**Windows** (10 или 11): бинарный файл появится в `target\release\snipdeck.exe`.

**Linux**: для сборки нужны заголовочные файлы GTK, X11/Wayland, трея, D-Bus и GL.
В Debian/Ubuntu:

```bash
sudo apt install libgtk-3-dev libxcb1-dev libxcb-render0-dev libxcb-shape0-dev \
  libxcb-xfixes0-dev libxcb-randr0-dev libxrandr-dev libxkbcommon-dev \
  libwayland-dev libayatana-appindicator3-dev libfontconfig-dev libdbus-1-dev \
  libgl1-mesa-dev libegl1-mesa-dev
```

PipeWire при сборке не нужен: он загружается во время выполнения для захвата
в Wayland. Чтобы установить свою сборку так же, как устанавливается релиз, разместите
её рядом с установщиком:

```bash
packaging/linux/install-from-source.sh   # builds, stages afresh, installs
```

## 🌍 Языки

Snipdeck полностью локализован. При первом запуске он выбирает ваш язык по локали ОС;
переопределить его можно в любой момент через **`⋯` → Язык** на панели инструментов.

> Английский · Испанский · Упрощённый китайский · Хинди · Арабский · Португальский · Русский · Японский ·
> Немецкий · Французский · Корейский · Итальянский · Турецкий · Индонезийский · Вьетнамский · Польский · Украинский ·
> Нидерландский · Персидский · Тайский · Бенгальский · Урду · Румынский

Всё приложение — как интерфейс Slint (`@tr`), так и сообщения на стороне Rust (`i18n::t`) — читается из
**одного gettext-файла `.po` на язык** в `lang/<code>/LC_MESSAGES/snipdeck.po`, встроенного в
бинарный файл во время сборки (без зависимости от gettext во время выполнения).

<details>
<summary><b>Добавление или обновление перевода</b></summary>

1. Новые строки оборачиваются в `@tr("…")` (в `.slint`) или `i18n::t("…")` (в Rust).
2. `lang/snipdeck.pot` — это шаблон, в котором перечислены все английские строки.
3. Скопируйте новый msgid в каждый `lang/<code>/LC_MESSAGES/snipdeck.po` и заполните его `msgstr` —
   сохраняя плейсхолдеры (`{}`, `{e}`, `{url}`, `{path}`) и escape-последовательности `\r\n` без изменений.
4. Чтобы добавить новый язык, создайте его `.po` и добавьте код в `LANGUAGES` и `po_source()`
   в `src/i18n.rs`.

</details>

## 🔒 Конфиденциальность и безопасность

- **Захват и OCR выполняются локально.** OCR использует `Windows.Media.Ocr` в Windows и
  Tesseract в Linux (данные передаются через канал, без временного файла); ничего
  не отправляется куда-либо для захвата или индексации. В Wayland экран считывается через
  портал ScreenCast: вы даёте разрешение один раз, а индикатор демонстрации экрана
  появляется только в момент создания снимка.
- **OCR + Перевод сначала спрашивает.** В первый раз он объясняет, что распознанный
  *текст* — но никогда не изображение — отправляется в Google Translate, и ждёт вашего согласия.
  Текст передаётся в теле запроса, а не в URL.
- **Загрузки каждый раз сначала спрашивают.** Ничто не покидает вашу машину, пока вы
  не нажмёте **Загрузить** в окне, которое называет хостинг и его адрес и объясняет, что
  это значит: любой, у кого есть ссылка, может открыть изображение, загрузку на catbox
  нельзя удалить, обычный сервер `http://` передаёт его без шифрования. Не загружайте
  конфиденциальное содержимое на хостинг, доступный всем по ссылке. API-ключи из
  импортированного файла `.sxcu` хранятся в `settings.json` — так же, как их хранит ShareX.
- **Копии для передачи остаются приватными.** Изображения, передаваемые почтовому клиенту
  или редактору, попадают в папку, доступную для чтения только вам (`$XDG_RUNTIME_DIR` в Linux,
  `%TEMP%\Snipdeck` в Windows), и затем удаляются.
- **Журналы не хранят следов.** Координаты указателя и заголовки окон записываются
  в журнал только на уровне отладки.
- **Запуск при входе основан на файлах.** Обычный ярлык в `shell:Startup` в
  Windows (а не ключ `HKCU\…\Run`, который средства защиты помечают чаще всего), запись
  автозапуска XDG в Linux.

## 🗺️ Дорожная карта

- [x] Windows 10 / 11
- [x] **Linux / GNOME** (Wayland) — с прилагаемым расширением оболочки: захват
      через `Super`+`Alt`+перетаскивание или горячими клавишами, снимки появляются там, где были сняты,
      и остаются поверх окон, OCR, выбор цвета
- [~] **Linux / другие рабочие окружения** — захват горячими клавишами и с панели инструментов,
      OCR, выбор цвета (через портал рабочего стола). Жеста «модификатор + перетаскивание»
      вне GNOME нет: для него нужен глобальный хук указателя, а Linux даёт его только
      через чтение `/dev/input` — то есть общесистемный кейлоггер, включить который
      Snipdeck вас просить не станет. В Wayland без расширения не работают размещение
      окон и режим «поверх всех окон» (см. ниже)
- [ ] **macOS** — в разработке
- [ ] Окно настроек внутри приложения
- [ ] Больше инструментов аннотации (размытие / пикселизация, нумерованные значки шагов, перемещение/редактирование фигур)

### Запуск в Linux

Установите приложение и **запускайте его из меню приложений**, а не из терминала.
Глобальные сочетания клавиш проходят через портал рабочего стола, который отклоняет сеанс
клиента без идентификатора приложения, а приложение вне песочницы получает такой идентификатор,
только когда рабочее окружение запускает его из записи `.desktop` — см. `packaging/linux/snipdeck.desktop`.

Зависимости времени выполнения: `libayatana-appindicator` (трей), `xdg-utils` (функция «Поделиться»)
и `tesseract` вместе с нужными языковыми данными (OCR — необязательно; без него OCR
просто пропускается, а не завершается ошибкой).

**Чего не позволяет Wayland.** Клиент Wayland не может сам размещать свои окна,
узнавать, где они находятся, или требовать, чтобы они оставались поверх других, — всё это
решает композитор. Поэтому в «голом» сеансе Wayland снимок открывается там, куда его
поместит композитор, а не над областью, с которой он был снят, не может висеть поверх
других приложений и появляется в списке окон. Всё остальное — захват области,
замороженный оверлей, глобальные сочетания клавиш, OCR, перетаскивание, контекстное
меню — работает.

KDE и композиторы на wlroots (sway, Hyprland, river, COSMIC) предоставляют
`wlr-layer-shell`, который даёт ровно эти три возможности; Snipdeck пока его не
использует. GNOME/Mutter отказался его реализовывать.

**В GNOME этот пробел закрывает расширение оболочки.** То, чего не может клиент, может
код, работающий внутри GNOME Shell. Поэтому `install.sh`, обнаружив сеанс GNOME, также
устанавливает `snipdeck@revisetouch.com` (из `packaging/gnome-extension/`) — единственный
файл, который следит за окнами снимков Snipdeck и размещает их там, где они были сняты,
держит их поверх других окон, закрепляет на всех рабочих пространствах и убирает из
переключателя окон. Положение передаётся в заголовке окна, который у этих окон без рамок
никогда не виден.

Расширение также возвращает жест захвата. В GNOME `Super`+перетаскивание
уже перемещает окна, поэтому жест — **`Super`+`Alt`+перетаскивание**; он активен, пока
запущен Snipdeck:

| Жест (GNOME) | Результат |
|---|---|
| `Super`+`Alt` + перетаскивание | Плавающий снимок на экране |
| `Super`+`Alt`+`Ctrl` + перетаскивание | Плавающий снимок **и** копирование в буфер обмена |
| `Super`+`Alt`+`Shift` + перетаскивание | Только галерея (без плавающего окна) |
| `Super`+`Alt`+`Ctrl`+`Shift` + перетаскивание | Галерея **и** буфер обмена, без плавающего окна |

У режима «Только буфер обмена» (`Win`+`Alt` в Windows) здесь нет жеста — используйте его
горячую клавишу. `Esc` отменяет перетаскивание, а если не отпускать `Super`+`Alt`, можно сделать
несколько снимков подряд.

После установки выйдите из сеанса и войдите снова: в Wayland GNOME Shell не может
перезагрузить расширения на лету, потому что он *и есть* композитор, на котором держится ваш сеанс.
Расширение совершенно необязательно — без него Snipdeck ведёт себя как любой другой
клиент Wayland, — и, кроме собственных окон Snipdeck, оно затрагивает только
`Super`+`Alt`+перетаскивание и только пока Snipdeck запущен.

Чего пока нет в GNOME Wayland: перетаскиваемый снимок перемещает Mutter, и приложение
так и не узнаёт, где он оказался, поэтому его положение не запоминается между
перезапусками.

## ⚙️ Конфигурация

Настройки хранятся в формате JSON и создаются при первом запуске. Окна настроек пока нет — отредактируйте
файл напрямую, затем перезапустите Snipdeck.

| Путь | Содержимое |
| --- | --- |
| `%APPDATA%\Snipdeck\settings.json` | Пользовательские настройки (ниже) |
| `%LOCALAPPDATA%\Snipdeck\` | `snips.db`, `state.json` и `cache\` с изображениями и миниатюрами |
| `Pictures\Snipdeck\` | Папка по умолчанию для *Сохранить* |

<details>
<summary><b>Избранные ключи <code>settings.json</code></b></summary>

| Ключ | По умолчанию | Значение |
| --- | --- | --- |
| `language` | `"auto"` | Код языка интерфейса или `"auto"` для следования ОС |
| `dark_theme` | `true` | Светлая или тёмная оболочка |
| `upload_service` | `"catbox"` | Хостинг изображений для *Загрузить*: `"catbox"` (без ключа), `"imgur"` или `"custom:<name>"`; задаётся через `⋯` → Загрузить на |
| `upload_hosts` | `[]` | Хостинги, импортированные из файлов ShareX `.sxcu`, с именами полей самого ShareX |
| `imgur_client_id` | `""` | Imgur Client-ID, требуется только когда `upload_service` равно `"imgur"` |
| `translate_target` | `"en"` | Код целевого языка по умолчанию для OCR-перевода |
| `translate_favs` | `["en","es","fr","de","it","pt","ru","ar"]` | Языки быстрого выбора во всплывающем окне перевода |
| `default_format` | `"png"` | Расширение по умолчанию для *Сохранить* |

**Сервисы загрузки** — *catbox.moe* (по умолчанию) не требует учётной записи или ключа, но анонимные загрузки
**впоследствии нельзя удалить**. *Imgur* требует бесплатный Client-ID (зарегистрируйтесь один раз на
imgur.com → Settings → Applications). В обоих случаях изображение не публикуется в списках, но любой, у кого есть
ссылка, может его открыть, и оно не зашифровано.

</details>

## 🧩 Архитектура

Однопоточный цикл событий Slint управляет интерфейсом; системные хуки и блокирующая работа выполняются в собственных
потоках и передают результаты обратно по каналам, опустошаемым раз за тик.

<details>
<summary><b>Карта модулей</b></summary>

| Модуль | Назначение |
| --- | --- |
| `src/app/` | Состояние приложения, цикл на каждый тик, действия интерфейса, модель галереи |
| `src/capture.rs`, `src/dxgi_capture.rs` | Захват монитора (DXGI Desktop Duplication, резервный вариант GDI) |
| `src/mouse_trigger.rs`, `src/native_mouse_trigger.rs` | Низкоуровневые хуки мыши/клавиатуры, которые запускают и ведут захват снимков |
| `src/slint_overlay.rs`, `ui/overlay.slint` | Полноэкранный оверлей выделения (живой или замороженный) |
| `src/floating.rs`, `ui/floating.slint` | Плавающие окна снимков (перетаскивание, изменение размера, обрезка, рамка) |
| `src/annotate.rs`, `ui/annotate.slint` | Редактор аннотаций (сведение tiny-skia, круг HSV, масштабирование) |
| `src/ocr.rs` | Обёртка `Windows.Media.Ocr` (в рабочем потоке) |
| `src/translate.rs`, `src/translate_popup.rs` | Всплывающее окно OCR-перевода |
| `src/share.rs`, `src/upload.rs` | Панель «Поделиться» / почта MAPI / редактор / загрузка на хостинг изображений |
| `src/sxcu.rs`, `src/upload_window.rs`, `ui/upload.slint` | Пользовательские загрузчики ShareX; окно согласия / хода / результата загрузки |
| `src/tray.rs`, `src/autostart.rs`, `src/single_instance.rs` | Значок в трее, запуск при входе, защита от запуска нескольких экземпляров |
| `src/snip.rs`, `src/settings.rs`, `src/paths.rs` | Сохранение галереи (SQLite + FTS), настройки, пути |
| `src/image_files.rs`, `src/atomic_file.rs` | Изображения снимков на диске: WebP без потерь, атомарная запись |
| `src/i18n.rs`, `lang/` | i18n во время выполнения + встроенные gettext-каталоги `.po` (23 языка) |

</details>
